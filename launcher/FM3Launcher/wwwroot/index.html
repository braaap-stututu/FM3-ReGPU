About FM3:ReGPU

A native PC port of Forza Motorsport 3 (Xbox 360). The game's PowerPC code is statically recompiled to x64 with XenonRecomp, it runs on its own implementation of the Xbox 360 kernel, and a native Direct3D 12 renderer (ReGPU) replaces the console's GPU.

No game data is included: it plays from your own copy of the disc.

Built the same way as the FM2 and FM4 ReGPU ports, and shares their kernel, renderer and this launcher.

Play in VR

Starts the game with the headset on, using this tab and the Graphics tab's other settings (upscalers and edge filters are off in stereo). The Play tab's button starts it without VR.

Integrated GPUs

Options for laptops and other computers whose graphics are built into the processor (Intel Iris Xe and UHD, AMD Radeon graphics). They are new and mostly untested on Intel: try one at a time, run the benchmark (Settings) or a race, and compare. Every option here is read when the game starts.

Linux

On Linux the game (a Windows program) runs through Proton or Wine. Proton is the tested way: umu-launcher runs it outside Steam; Steam's own Proton (or GE-Proton) works too. All of them keep the game's Windows side in one folder (the prefix).

Shader cache

Shaders are compiled the first time they're needed and kept here, so later starts and races don't stutter.

Benchmark

The game's own race AI drives your car through a career race (Ladera Test Track, 3 laps, 7 opponents) while the frame rate is measured, then the game closes by itself. It races on a copy of the Baseline profile, so your saves don't change. Uses the settings on these tabs. The AI drives a little differently each time: run it a few times before comparing settings.
